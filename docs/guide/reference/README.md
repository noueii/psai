# Reference

One page per kind of file in a stack. The agent-facing source of truth is the `customize-harness` skill's [LAYOUT.md](../../../skills/customize-harness/LAYOUT.md) and [FORMATS.md](../../../skills/customize-harness/FORMATS.md); these pages explain the same formats for people.

- [stack.md](stack.md): a stack repo: layout, names, manifests, versions, CI
- [workflow.md](workflow.md): a workflow skill and its `workflow.yaml`
- [step.md](step.md): a step
- [role.md](role.md): a role, its diff limit, its model and its knowledge
- [guide.md](guide.md): a guide
- [template.md](template.md): a template
- [rules.md](rules.md): the `<stack>-rules` skill
- [shared.md](shared.md): the `<stack>-shared` skill and `skill:path` refs
- [skill.md](skill.md): a stack's own skill, and skills a role requires
- [cases.md](cases.md): simulator cases and eval scenarios
- [knowledge.md](knowledge.md): your knowledge, inboxes and the stage
- [escalation.md](escalation.md): the fixed block
