# A template

`templates/<name>.md`: the exact format of an output, then a filled-in example. Attach it with `read:` to the step that writes the output.

```md
# Report

## Summary
## Tests
## Open

## Example
# Report
## Summary
- Added `reverse(text)` to textkit.
## Tests
- `python3 -m unittest -q`: 5 tests pass.
## Open
- None.
```
