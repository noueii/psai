# guides/

How one kind of work must be done (prescriptive), written by the owner. A step or role loads a guide by listing it in `read:`. Name: `<topic>-rules.md` or `<topic>.md`. Example: [evals/fixtures/harness-content/guides/example-rules.md](../evals/fixtures/harness-content/guides/example-rules.md).

Format: a title, then short rules as bullets. Each rule comes from the owner, never invented. A starter guide says so in its header.
