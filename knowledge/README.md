# knowledge/

What's true and what was decided and why: descriptive, dated, sourced. Agents write only to inboxes (`capture-knowledge`); promotion to `facts/` and `decisions/` happens by PR. Read [INDEX.md](INDEX.md) on demand.

- `inbox.md`: shared findings, not yet promoted.
- `facts/<topic>.md`: promoted facts.
- `decisions/<date>-<slug>.md`: promoted decisions.
- `roles/<role>/{INDEX.md,inbox.md}`: per-role knowledge, created along with each role.
