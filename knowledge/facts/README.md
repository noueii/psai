# knowledge/facts/

Promoted facts: things that are true about the owner's repos, tools or environment, each with its source. Name: `<topic>.md`. Format: a title, then bullets of `- <fact> (source: <where it was verified>, <date>)`. Example entry: `- pi 0.80.2 has no subagents (source: pi --help, 2026-11-21)`.
