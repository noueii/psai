# A final report template

**What:** every task ends with the same short report.
**Why:** the human reads one predictable shape instead of a transcript.
**How:** a template such as `templates/report.md` in the workflow's folder (or `<stack>-shared:templates/report.md`), attached with `read:` to a last step before the terminal node. Ask the owner for the sections, e.g. what changed, how it was checked, what's still open.
