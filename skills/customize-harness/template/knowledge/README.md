# knowledge/

What's true and what was decided, read from this clone (it doesn't ship with the skills). `inbox.md` and `roles/<role>/inbox.md` collect dated entries during tasks (capture-knowledge); the retro promotes them by PR into `facts/<topic>.md` and `decisions/YYYY-MM-DD-<slug>.md`, and lists every file in `INDEX.md`. Example: `facts/release-process.md`.
