# skills/

Everything this stack ships: flat `skills/<name>/SKILL.md`, `name` equal to the folder, every name starting with the stack's name. Workflows are `workflow-<stack>-<name>/` (SKILL.md, workflow.yaml, steps/), shared roles, guides and templates `<stack>-shared/`, rules for every task `<stack>-rules/`. Formats: psai's `customize-harness` skill, FORMATS.md. Example: `workflow-<stack>-change/SKILL.md`.
