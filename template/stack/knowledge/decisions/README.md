# knowledge/decisions/

Decisions behind this stack's workflows and rules. Name: `YYYY-MM-DD-<slug>.md`. Format:
```md
# YYYY-MM-DD: <title>
- Decision: <what>
- Why: <reason, or "not stated">
- Source: <who decided, where>
```
Decisions about psai itself live in psai's `docs/decisions/`, not here.
